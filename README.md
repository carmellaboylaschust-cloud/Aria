# Aria

An anime-inspired wallpaper studio for Codex on Windows, with live skin switching, animated backgrounds, Steam Workshop imports, and a home for your prompts.

把喜欢的风景，带进日常。

Aria 把挑壁纸、整理收藏和桌面换肤放在了一起。你可以在海盐珊瑚色的界面里逛逛创意工坊，收下喜欢的角色壁纸，再把它应用到正在使用的 Codex。图片、动图和视频都能成为背景，常用的提示词也有自己的小屋。

项目基于 [Codex Dream Skin](https://github.com/Fei-Away/Codex-Dream-Skin) 开发，由社区维护。目前提供 **Windows 11 x64 源码预览版（0.1.0）**，适配 **Microsoft Store 安装的 Codex 桌面端**。安装程序通过应用包 `OpenAI.Codex` 查找它；这个应用的进程名为 `ChatGPT.exe`，因此部分界面沿用了“桌面 ChatGPT”的称呼。

## 在 Aria 里逛一逛

- **发现灵感**：首页展示四张壁纸，每天按系统时间 04:00 更新推荐，也可以手动切换。点下“保存这份风景”，喜欢的图片就会留在本地收藏里。每日更新只影响首页推荐，对话背景由你自己选择。
- **我的皮肤**：把图片、GIF、动态 WebP 和视频放进收藏，按分组、标签或喜好整理。预览时可以调整显示方式和界面不透明度；默认值为 30%。想整理空间时，也可以直接移除皮肤。
- **创意工坊与鸣潮专区**：在应用内浏览 Steam 创意工坊和呜哇小站，从已下载的工坊项目中挑选壁纸，或把网页上的喜欢的图片保存下来。
- **转换任务**：把 Wallpaper Engine 的 Scene / Web 壁纸加入队列，Aria 会安排播放和录制，完成后放入“我的皮肤”。转换期间可以继续浏览其他页面。
- **提示词小屋**：整理常用模板，写下这次想做的事，再从这里打开桌面端开展工作。适合给写作、学习、代码和日常规划各留一个顺手的起点。
- **隐藏收藏**：用自己设置的问题打开隐藏皮肤列表。管理员可以维护问题库和修改密码，首次使用时由你设置个人验证资料。问答控制 Aria 内的列表访问，原素材仍保存在本地文件夹中。

## 从第一张壁纸开始

当前版本通过源码安装。应用、壁纸和运行资料统一放在 `D:\Aria`，仓库附带海盐珊瑚渐变示例和原创导航图形，方便安装后开始体验。

1. 按照 [安装与构建](docs/INSTALL.md) 准备 Node.js、WebView2 等依赖，运行安装脚本。视频处理需要 FFmpeg，工坊场景录制还需要已购买并安装的 Wallpaper Engine。
2. 打开 `D:\Aria\user-backgrounds\Aria.exe`，在“我的皮肤”里添加一张喜欢的图片。
3. 点击侧边栏的 **“打开并连接桌面端”**。如果 Codex 已从任务栏或其他入口运行，先保存工作并完整退出，再由 Aria 启动。Aria 使用独立的桌面会话资料目录，首次进入时可能需要登录。
4. 连接成功后，在皮肤预览中点击 **“应用到桌面端”**，就能看到新背景。此后，在这次连接会话中切换壁纸、调整不透明度都可以即时生效，当前对话会继续保留。

想使用隐藏收藏时，再到“偏好与存储 → 管理员与问题库”完成设置。具体操作见 [管理员与隐藏皮肤](docs/ADMIN.md)。

## 几个容易遇到的问题

### 先开 Codex，再开 Aria，怎样连接？

如果这次 Codex 是通过 Aria 启动的，重新打开 Aria 后可以继续连接。通过普通任务栏入口启动的 Codex，则需要先保存工作、完整退出，再点击 Aria 内的启动按钮。

原因在于换肤所用的调试连接需要随桌面进程一起启动。Aria 目前通过这个连接更新背景，所以首次启动的入口会影响能否接入。连接建立后，后续换肤就能直接在当前窗口里完成。

### 在创意工坊订阅后，壁纸怎样进入收藏？

在内嵌页面登录 Steam，选中壁纸并点击“订阅并导入”，Aria 会加入导入任务。**实际文件由本机 Steam 客户端下载**，请让客户端保持登录和运行；它可以留在后台。

下载完成后，Aria 会检查项目类型和大小：支持的视频可以直接入库，Scene / Web 项目会进入录制队列。已经下载过的壁纸也可以从“已下载壁纸”中手动选择。希望后续订阅自动加入收藏时，可在“偏好与存储”开启“新订阅下载后自动入库”，并设置大小上限。超出上限或格式受限的项目会显示具体原因。

### 动态壁纸都会转成 1080p 吗？

支持的视频可以保留源分辨率导入，例如符合格式与大小要求的 4K 视频。GIF 和动态 WebP 也可以作为动态背景使用。

Wallpaper Engine 的 Scene / Web 壁纸则采用另一条处理流程：由 Wallpaper Engine 播放，Aria 将一段画面录成 **1920 × 1080、30 帧、静音视频**。你可以选择录制时长，完成后得到可循环播放的背景。原场景里的鼠标交互、实时数据等效果会固定为录制时的画面。录制期间请保持电脑解锁。

### 版本更新后出现连接问题，怎样反馈？

Aria 依赖 Codex 的桌面页面结构和本机调试连接。Codex 更新后，连接识别或背景样式可能需要随之调整。遇到问题时，请在 [Issues](https://github.com/carmellaboylaschust-cloud/Aria/issues) 中附上 Windows、Codex 和 Aria 的版本，以及启动入口、复现步骤和报错截图，便于定位具体环节。

本次源码发布已检查独立安装、启动器构建、默认皮肤初始化、管理员流程和媒体目录访问；详细结果放在 [发布检查记录](docs/RELEASE_REVIEW.md)。

换肤使用的本机调试连接具备读取和控制桌面会话的权限，同一电脑上的其他程序也可能访问它。请在自己信任的电脑和软件环境中使用；连接机制、登录资料存放与保护方式见 [安全说明](SECURITY.md) 和 [数据与隐私](PRIVACY.md)。
