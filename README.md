# Aria

把喜欢的风景，带进日常。

Aria 是面向 Windows 11 的桌面皮肤工作室，基于 Codex Dream Skin 扩展了壁纸管理、即时换肤、Steam 创意工坊浏览和本地转换队列。海盐珊瑚配色搭配独立导航图形，让常用操作集中在一个窗口里。

项目采用社区维护方式。当前适配对象为 Microsoft Store 的 `OpenAI.Codex` 桌面应用，其进程名称为 `ChatGPT.exe`。兼容性以实际软件版本和验证结果为准。

## 可以做什么

- **管理皮肤**：导入图片、动图和视频，预览、收藏、分组、添加标签、隐藏或卸载皮肤副本。
- **即时换肤**：从 Aria 打开并连接桌面端后，在当前连接会话中切换背景与界面不透明度。默认不透明度为 30%。
- **浏览壁纸**：内嵌 Steam 创意工坊与呜哇小站，已下载的工坊项目可导入；网页图片可保存到本地收藏。
- **后台转换**：Scene 与 Web 项目交给本机 Wallpaper Engine 播放并录制为 1080p、30 帧、静音视频；已有兼容视频保留源分辨率。
- **提示词小屋**：编辑模板并组合本次任务，通过桌面端开始工作。
- **隐私管理**：随机问题解锁隐藏列表；管理员密码用于维护问题库和修改密码。
- **日常整理**：首页每日 04:00 更新四张推荐，已保存的收藏独立保留；备份、恢复与空间检查集中在偏好页。

## 开始使用

当前为 0.1.0 源码预览版。当前为 0.1.0 源码预览版。公开版本提供源码、原创示例图形和本地构建脚本。安装目标为 `D:\Aria`，用户素材与运行数据也写入该目录。首次安装请按 [安装与构建](docs/INSTALL.md) 准备依赖。

1. 阅读 [安全说明](SECURITY.md)，了解本机调试连接的权限范围。
2. 在 Windows PowerShell 中运行安装脚本，完成依赖检查和启动器构建。
3. 打开 `D:\Aria\user-backgrounds\Aria.exe`，进入「偏好与存储 → 管理员与问题库」设置个人密码和验证问题。
4. 添加喜欢的图片，点击「打开并连接桌面端」。首次接入时，先保存桌面端工作并退出原来的桌面会话。
5. 连接成功后，皮肤预览中的应用按钮可即时更新背景。

若桌面端已通过原入口启动，Aria 会提示连接条件，并等待用户保存工作后退出。Chromium 调试入口在进程启动阶段建立，后续换肤复用该连接。

## 使用前了解

换肤使用回环地址上的 Chromium 调试端口。此端口具备读取和控制当前桌面页面的权限，本机其他程序也可能访问。请在可信设备和可信软件环境中使用。独立资料目录用于区分换肤会话；登录后，该会话仍包含账号信息。具体边界见 [安全说明](SECURITY.md)。

Steam 网页订阅和客户端文件下载分别由 Steam 网站与本机客户端完成。Scene / Web 录制需要已安装并获得使用许可的 Wallpaper Engine；Web 项目中的脚本在录制期间由其运行。自动导入初始处于关闭状态，可在了解素材来源后开启。
