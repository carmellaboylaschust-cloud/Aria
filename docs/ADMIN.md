# 管理员与隐藏皮肤

管理员是 Aria 内的本地功能角色，用于维护验证问题和管理员密码。Windows 账户、GitHub 仓库权限和桌面聊天账号各自使用自己的验证体系。

## 首次设置

打开「偏好与存储 → 管理员与问题库」。新安装会显示设置窗口，依次填写 12 至 128 字的密码、重复密码、一个验证问题及答案。建议使用密码管理器生成独立长密码，并保存好记录。

创建完成后，输入刚设置的密码进入管理页，可继续添加问题。问题库支持 1 至 20 道题，每次进入隐藏列表随机选择一道。题目支持 2 至 100 字，答案支持 1 至 64 字。中文输入使用页面原生输入框。

## 日常管理

管理窗口可编辑题目、更新答案和修改密码。已有题目的答案框留空时，原答案继续生效。修改密码需要当前密码，并填写两次新密码。保存后，管理员权限和隐藏列表会重新锁定。

权限凭证有效期为 15 分钟，并绑定 Aria 的进程与启动时间。关闭问题库窗口会收回该窗口的管理员权限；连续五次验证失败后暂停尝试 30 秒。

旧安装已有的密码、问题和隐藏列表继续保留。新密码规则在创建和修改时生效。初始化流程只创建新的本地配置，已有配置进入正常密码验证流程。

## 保护范围与找回方式

隐藏功能用于控制 Aria 界面的列表可见性，磁盘上的图片和视频继续保留。文件层面的保密需求适合配合 Windows 账户隔离及磁盘加密。密码和答案以加盐派生值保存，隐私配置使用当前 Windows 用户的 DPAPI 保护。

忘记管理员密码时，优先从自己的密码管理器找回。维护者能够协助检查本地配置状态；密码恢复由使用者掌握的凭据和备份决定。迁移到另一 Windows 账户前，先通过应用导出加密隐藏备份，并妥善保存其独立密码。
