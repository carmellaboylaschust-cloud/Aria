# 架构与维护

Aria 由 C# 启动器、PowerShell 宿主、WebView2 界面及 Node.js 换肤引擎组成。

`launcher` 构建隐藏终端的 Windows 启动入口。`engine/hub` 提供 HTML、CSS 与前端交互，宿主仅接受主界面可信来源的消息。`engine/scripts` 负责文件管理、导入队列、隐私验证、桌面连接与调度。`engine/assets` 提供注入样式、校验规则、辅助代码与原创默认背景。

主界面、Steam、鸣潮网页各自保持独立 WebView2 环境。媒体虚拟域名映射到明确的媒体子目录，登录资料与验证文件保留在这些映射之外。背景任务通过本机文件队列通信，长期媒体工作由独立进程完成。

桌面启动阶段建立回环 CDP 连接；持续注入器应用背景和样式并检查目标身份。视频保持静音循环，窗口可见性与播放偏好影响暂停行为。Scene / Web 转换将 Wallpaper Engine 的可渲染窗口交给录制流程，产物验证通过后加入皮肤库。

管理员功能采用显式首次初始化。验证配置按 Windows 用户加密保存，密码与答案使用随机盐和 PBKDF2-SHA256 派生值。短期权限凭证区分管理员与隐藏列表访问，绑定进程与到期时间。文件本身的保密边界由 Windows 权限和存储加密决定。

维护时优先关注外部桌面版本变化、WebView2 页面来源、路径边界、子进程参数、任务状态持久化及媒体解析器更新。每次发布以独立清单核对源码与个人数据的分界。
