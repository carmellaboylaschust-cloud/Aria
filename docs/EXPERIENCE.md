# 日常使用体验更新

本轮改进围绕浏览、整理和工作衔接展开，沿用海盐珊瑚配色与现有页面结构。

## 浏览与整理

- 页面会记住本次打开期间的滚动位置、搜索和筛选状态，切回来可以继续浏览。
- 皮肤卡片上的爱心支持直接收藏，键盘操作后焦点停留在原来的按钮。
- 图库仅更新变化的卡片，高清静态图片使用最大 960 像素的缓存封面。预览和桌面继续读取原素材，小尺寸图片保持原始尺寸。
- 批量整理为分组和标签分别提供“保留各自原值”“统一修改”“清空”。只修改分组时，各张皮肤原有标签继续保留。

## 视频与转换

- 视频预览中可以拖动进度，选择“用当前画面作封面”；“恢复自动封面”会重新选择较明亮的画面。
- 手选封面随源视频记录，自动扫描和封面缓存重建都会保留选择。
- 转换任务可暂停后续处理，当前任务完成后休息；恢复队列后继续执行。排队任务可以设置优先顺序。
- 封面定期全量检查调整为五分钟一次，新素材和缺失封面及时处理。后台快照超时会自动恢复，空闲最小化期间降低刷新频率。

## 工作与换肤

- 每份提示词拥有独立草稿，并保留最近六份历史。旧版草稿会自动迁移，“草稿与历史”入口支持选择和恢复。
- “我的皮肤”新增“恢复上一张”，在成功切换后可以恢复上一张皮肤及其不透明度、显示方式。首次切换后出现此入口。
- 换肤历史通过 Windows 用户加密保护，恢复时重新校验皮肤权限。隐藏收藏继续遵循问答解锁规则。

## 验证

新增隔离测试覆盖批量部分更新、草稿迁移与历史恢复、切页位置、直接收藏、键盘焦点、静态缩略图、手选视频封面、队列暂停与排序、后台超时恢复和加密换肤历史。既有视频界面与快照权限测试继续通过。
