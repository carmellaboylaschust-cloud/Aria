## 验证范围

本次发布采用源码预览版。现有个人版的换肤和媒体处理流程为实现基础；本轮重点验证公开版新增的安装与安全边界。每种第三方壁纸、未来桌面应用版本、网站登录状态和长时间播放表现需要在各自环境中持续验证。完整桌面登录与全部外部网站流程由使用者在本机完成。

CDP 的本机控制能力仍属于架构风险，具体范围见 `SECURITY.md`。问答隐藏属于应用界面访问控制，文件保密依靠 Windows 权限和存储保护。该记录表达本次检查范围与结果，后续发布按变更继续复核。
